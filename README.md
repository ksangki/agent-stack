# 에이전트가 사는 곳 — 모델은 어디서 돌리고, SaaS는 어떻게 사며, 통제권은 어디에 남는가

> **초안 판본 (v1.0.0) — 저자가 원고 전문을 검토하기 전에 공개한 판본입니다.** 내용은 바뀔 수 있습니다.

2026년, 기록 시스템을 파는 벤더들이 화면을 거치지 않고 기능을 부르는 경로를 스스로 열었고, 대기업 100곳 조사에서는 세 개 이상의 모델 계열을 쓰는 곳이 81%였다. 이 책은 로컬 모델과 클라우드를 섞는 하이브리드 배치와 에이전트가 화면 대신 호출로 쓰는 SaaS를 한 권으로 엮은 설계서다. 끌고 가는 질문은 하나다. **에이전트 시대에 조직의 통제권은 어디에 남는가.** 답의 형태는 세 가지 — 모델이 로컬과 클라우드로 갈라지고 소프트웨어가 화면과 데이터로 갈라져도, 조직이 붙잡을 것은 **데이터·권한·경계** 규칙이다.

장마다 그 장의 결정에 쓸 **가져갈 도구**(표·체크리스트·계산 양식)를 두었고, 도구 24개는 맺는 장에서 세 규칙으로 다시 묶었다. 근거가 약하거나 중간인 전망은 **가설 카드** 16장으로 떼어 부록 B의 2027년 말 점검표에 모았다. 카드마다 받아들임·범위 축소·보류·버림을 고르는 판정 칸이 있어, 독자가 자기 조직의 기록으로 직접 판정할 수 있다.

## 이 책은 어떻게 만들어졌나

이 책의 리서치와 초안은 공개 저장소의 책 저술 하네스(book-writer v2.1.0) 위에서 AI 에이전트들이 썼다 — 「조직 에이전트 2027」의 리서치를 이어받은 웹(세 갈래)·커뮤니티·논문 리서치와 합성, 계획(저자 승인), 저술 전 사실 검증 48행, 저자 인터뷰 아홉 문항, 장별 저술과 사실 검증, 그림, 편집 통합, 교정 패스(원고 CI·writing-deslop), 앞 단계와 맥락을 공유하지 않는 수락 검수. 저자는 방향을 정하고, 계획을 승인하고, 인터뷰에 답했다. 경험을 묻는 질문에 "없어"라고 답한 장은 공개 자료만으로 썼다. 표지와 본문 그림 13점은 이미지 생성 도구 없이 스크립트로 그렸다. 자세한 내용은 책의 서문과 부록 C에 있다.
