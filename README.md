# 에이전트가 사는 곳 — 모델은 어디서 돌리고, SaaS는 어떻게 사며, 통제권은 어디에 남는가

> **초안 판본 (v1.1.0) — 외부 편집 검수서를 반영했지만, 저자가 원고 전문을 검토하기 전에 공개한 판본입니다.** 내용은 바뀔 수 있습니다.

2026년, 기록 시스템을 파는 벤더들이 화면을 거치지 않고 기능을 부르는 경로를 스스로 열었고, 대기업 100곳 조사에서는 세 개 이상의 모델 계열을 쓰는 곳이 81%였다. 이 책은 로컬 모델과 클라우드를 섞는 하이브리드 배치와 에이전트가 화면 대신 호출로 쓰는 SaaS를 한 권으로 엮은 설계서다. 끌고 가는 질문은 하나다. **에이전트 시대에 조직의 통제권은 어디에 남는가.** 답의 형태는 세 가지 — 모델이 로컬과 클라우드로 갈라지고 소프트웨어가 화면과 데이터로 갈라져도, 조직이 붙잡을 것은 **데이터·권한·경계** 규칙이다.

장마다 그 장의 결정에 쓸 **가져갈 도구**(표·체크리스트·계산 양식)를 두었고, 도구 24개는 맺는 장에서 세 규칙으로 다시 묶었다. 책 전체에서 가상의 요청서 하나 — 외부 AI 클라이언트의 에이전트를 고객 관리 SoR에 연결해 상담 기록을 요약하고 고객 레코드에 적게 하자는 요청 — 를 따라가고, 12장에서 그 요청서는 조건을 달고 돌아간다. 근거가 약하거나 중간인 전망은 **가설 카드** 16장으로 떼어 부록 B의 2027년 말 점검표에 모았다. 카드마다 받아들임·범위 축소·보류·버림을 고르는 판정 칸이 있어, 독자가 자기 조직의 기록으로 직접 판정할 수 있다.

## v1.1.0에서 달라진 것

외부 편집 검수서를 저자 결정으로 전부 반영했다. 사실 검증 에이전트가 검수서의 지적과 문장 수정안 35건을 1차 원문에 다시 대조했고(V1~V20), 편집은 그 대조 결과를 따라 3~12장의 사실 문장을 고쳤다. 검수서가 짚지 않은 오류(3장 Purview의 레이블 표시·상속 설명 등)도 이때 바로잡았다. 용어 넷을 바꿨다 — "답 열람자"는 "결과를 볼 수 있는 사람"으로, "허용 동사"는 "허용 작업"으로, "권한 승인 위치"는 "권한을 승인하는 시스템"으로, "민감 스위치 원장"은 "민감정보 설정 목록"으로. 바뀐 용어와 내용에 맞춰 본문 그림 6점(2-1, 3-1, 5-1, 8-1, 9-1, 11-1)을 다시 그렸다. 가상 요청서를 서문에서 먼저 소개해 여러 장에 이어 붙이고, 2장의 배치 위치를 겹칠 수 있는 대표 구성 여섯 가지로 정리하고, 4장과 7장에 가상 값 계산 예시를 넣고, 5장에서 라우팅 기능과 정책 집행 기능을 나눴다. 가설 카드 S5-2의 근거 강도를 약으로 바로잡아 카드 16장의 집계는 중 7·약~중 2·약 7이 됐다(카드 수는 그대로). 참고문헌에는 공개 출처 5건의 서지를 복원했고, 본문은 업종으로 일반화한 표기를 유지한다. 표지를 교체하고 삽화 7점을 더했다. 수락 검수를 다시 거쳤다.

## 이 책은 어떻게 만들어졌나

이 책의 리서치와 초안은 공개 저장소의 책 저술 하네스(book-writer v2.1.0) 위에서 AI 에이전트들이 썼다 — 「조직 에이전트 2027」의 리서치를 이어받은 웹(세 갈래)·커뮤니티·논문 리서치와 합성, 계획(저자 승인), 저술 전 사실 검증 48행, 저자 인터뷰 아홉 문항, 장별 저술과 사실 검증, 그림, 편집 통합, 교정 패스(원고 CI·writing-deslop), 앞 단계와 맥락을 공유하지 않는 수락 검수. 저자는 방향을 정하고, 계획을 승인하고, 인터뷰에 답하고, v1.1.0에서 외부 편집 검수서를 전부 반영하기로 정했다. 경험을 묻는 질문에 "없어"라고 답한 장은 공개 자료만으로 썼다. 번호를 붙인 본문 그림 13점은 각 장 원고의 사실만으로 스크립트가 그린 도식이다. v1.1.0의 표지와 삽화 7점(부 도입면 4점, 4·8·12장 3점)은 외부 검수자가 이미지 생성 도구로 만든 시안을 저자가 채택한 그림이고, 상상으로 그린 장면이다(실제 조직·시설·제품 화면이나 시스템 구조가 아니다). 외부 편집 검수는 저자의 전문 검토를 대신하지 않는다. 자세한 내용은 책의 서문과 부록 C에 있다.
